# Gift Mall · 礼品库特卖管理系统

内网「员工福利 / 礼品库特卖」平台：员工用浏览器自助浏览、下单，管理员在后台维护商品、发放订单、导出台账。

**纯 Python 标准库实现（后端），零第三方依赖；前端为原生 HTML / CSS / JavaScript。** 打包后是单个绿色 exe，双击即可运行，无需安装 Python、无需管理员权限。

## 功能一览

### 前台（员工）

- 商品卡片网格：图片、名称、规格、价格、库存、有效期；搜索 + 价格 / 库存排序
- 商品详情抽屉 + 多图灯箱：滚轮以光标为中心缩放（1×~4×）、单击放大、拖拽平移、移动端双指捏合
- 购买清单（购物车）、实时库存与限额校验、下单生成单号
- 订单查询：凭单号 / 姓名 / 手机号查自己的订单与状态
- 特卖活动开关：结束后前台停止展示并禁止下单，重开即开启新一期

### 后台（管理员，口令登录）

| 模块 | 说明 |
|---|---|
| 数据看板 | 商品 / 订单统计、本期已售出件数、临期与过期预警、下单趋势图 |
| 礼品管理 | 增删改、批量修改、列表内快捷调库存、多图上传、Excel 模板批量导入、图片随删除自动回收 |
| 购买订单 | 待发放 → 确认发放 → 实物已领（流程终点，锁定不可回退）；取消 / 撤销均有二次确认；记录下单来源主机与 IP |
| 操作日志 | 全程审计留痕 |
| 设置 / 导出 | 特卖开关、每人每月购买件数限额；库存台账 + 购买记录 xlsx 导出；数据库一键备份 |

## 技术要点

- 后端：`http.server` 自研轻量路由（`gm/`），SQLite 单文件存储，WAL 模式
- 前端：无框架、无构建步骤，静态资源直接托管
- 老库自动迁移：启动时 `init_db()` 自动补列，无需手动改表
- Excel 导入 / 导出：不依赖 openpyxl，用 zipfile + ElementTree 手写 xlsx 读写（`gm/xlsx.py`、`gm/xlsxread.py`）
- 打包：`build_exe.py` 一键 PyInstaller onefile，自动递增版本号并写入 exe 版本资源

## 快速开始

### 源码运行

```bash
# Python 3.10+，无第三方依赖
python run.py 9100,8010     # 前台 9100，后台同端口 /admin，8010 仅本机调试
```

浏览器打开 `http://127.0.0.1:9100`，管理后台 `/admin`，**默认口令 `admin888`，首次登录后请立即修改**。

首次启动自动生成 `data/`（数据库 + 示例数据），商品可通过后台「下载模板」填写后批量导入。

### 打包 exe

```bash
python build_exe.py            # 版本号自动 +1
python build_exe.py 1.2.0     # 或指定版本
```

产物在 `dist/gift-mall.exe`，拷到任意 Windows 机器双击运行（首次运行可能被杀软拦截，属 PyInstaller 常见误报，加白名单即可）。

## 目录结构

```
gift-mall/
├── gm/                 # 后端：httpd（路由）、api（接口）、store（业务）、xlsx / xlsxread
├── web/                # 前端静态资源（index / admin + js / css / svg）
├── run.py              # 入口：解析端口、启动 HTTP 服务
├── build_exe.py        # PyInstaller 打包脚本（含版本资源写入）
├── cleanup-data.py     # 数据清理 GUI 工具（清测试订单 / 日志 / 孤儿图片，强制先备份）
├── 使用说明.md          # 面向日常使用者的操作手册
└── 部署指南.md          # 面向部署者的迁移 / 自启 / 排障手册
```
